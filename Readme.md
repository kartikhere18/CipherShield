# CipherShield

A browser-based cybersecurity intelligence suite developed for academic cybersecurity learning and demonstrations.

## Features

- AES-256 Encryption & Decryption
- Network Vulnerability Scanner Simulation
- Browser Fingerprinting
- Cryptography Encoding Lab
- Cybersecurity Awareness Quiz

## Technologies Used

- HTML5
- TailwindCSS
- JavaScript
- CryptoJS
- Lucide Icons
